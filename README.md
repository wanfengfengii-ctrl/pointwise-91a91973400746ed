# 观测修订 × 固定校准的增量区间关联

## 索引
- `Engine(R)` 建立时按测点 `key` 为校准侧（右侧）建立静态**中心区间树**
  （`_build_tree`）：每个节点存 `center2 = start + end`（以双倍中心做整数
  比较，超大/负数端点不溢出）；跨中心的区间同时按 `start` 升序、`end` 降序
  排序，左右子节点只含完全落在中心一侧的区间。中位倍增中点保证两个孩子都是
  严格子集，构建用显式栈避免递归深度问题。
- `_probe_right(key, start, end)` 只沿树向下：端点完全在中心一侧时单序扫描并在
  越过端点后 `break`；跨越中心时读取节点上全部跨中心区间并下探两侧。探测返回
  与 `[start,end)` 实际相交的 `(rid, lo, hi)`。

## 每记录缓存（结果的唯一真源）
- `_left_cross[lid]  = {rid: 交集}` 与 `_right_cross[rid] = {lid: 交集}` 对偶。
- `_left_rows[lid]` 缓存该观测拥有的全部结果行（交集行 + 它自己的未匹配片段）。
- `_right_rows[rid]` 缓存该校准记录**仅为自身**的未匹配片段（交集行归左记录所有）。
  两侧缓存不重复地划分完整结果集（`read()` 由 `_rows` 维护）。
- 撤去一条覆盖只重算其**所属记录**的片段：未匹配片段由对侧覆盖并集的剩余部分
  决定，因此撤去重复覆盖的一条不会提前暴露未匹配片段。

## apply 的更新边界
1. 校验整批（非法即 `ValueError`，业务状态与计数均不变）。
2. 过滤真正的无变化 upsert / 缺失删除。
3. 用区间树探测**旧区间与新区间**，得到受影响校准 `rid` 与受影响左 `lid`。
4. 仅对这批记录取缓存、摘除旧对偶引用、重算并写回缓存。
5. `add = 新缓存行集 − 旧缓存行集`，`remove` 反之；不做全量重建/全表比对。

## 工作计数
- 索引探测中每个被检查的校准区间（含 `break` 前最后一个）记 `right_visits`。
- 覆盖重算：左记录自身坐标记 `left_visits`，其每个相交对端记 `right_visits`；
  右侧同理。摘除对偶引用也按被检查记录计所属侧。`read()` 不改计数。
- 固定稀疏基准 n=5000 单条更正实测 `left_visits=2, right_visits=40`（合计 42 ≤ 500）。

## 入口
- `python3 checks.py normal` —— 原回归（保持不变）。
- `python3 checks.py verify` —— 独立全量判定器 + 定向用例 + 随机/稠密批次 + 计数/规模。
- `python3 checks.py benchmark 5000` —— 稀疏基准，打印真实 delta 与 work。
- `python3 checks.py demo` —— 重叠撤回真实结果 + 稀疏更正真实 work。
